# imad7x.uk

My personal website, live at **[imad7x.uk](https://imad7x.uk)**. Self-hosted on my home server behind a Cloudflare Tunnel.

![Flying to Saturn in the solar system](assets/solar.gif)

- **Solar system**: an interactive 3D orrery you can fly around
- **Games**: eight small browser games, one with a multiplayer relay
- **Sunroom**: a realtime 3D hangout

Three.js, vanilla JavaScript, nginx, small Python realtime services, Docker.

🔒 Source is private; happy to walk through it on request.
